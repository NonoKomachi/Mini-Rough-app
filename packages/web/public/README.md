# ミニラフ小町

紙の「ミニラフ」(5cm角程度の小さな紙に荒くラフを描いて構図と勢いを固める手法)をデジタルで再現するための専用お絵かきアプリです。

## 基本の流れ

1. 「ファイル」→「新規」で完成サイズ・dpi・ミニラフ解像度を指定してキャンバスを作成します。
2. 小さな解像度のキャンバスに、鉛筆・ブラシ・透明ブラシ・消しゴム・ドットペン・バケツ塗りで描きます。
3. 「バリエーション」→「追加」で同じ設定の別案を並べて見比べられます。クリックした1枚だけが編集対象になります。
4. 「ファイル」→「出力」で、.clip / .psd / .png / .jpg / .bmp / .gif のいずれかで、完成サイズ・ミニラフサイズどちらでも書き出せます。
5. .clip書き出しは「ミニラフ (幅x高さ)」という名前のフォルダにまとめて入るので、CLIP STUDIO PAINT側で既存のファイルに結合しやすくなっています。
6. 自分で書き出した.clipは「ファイル」→「読み込み」で再度取り込んで編集を続けられます(他のソフトで作られた複雑な.clipは完全には再現できない場合があります)。「ファイル」→「保存」/「開く」はアプリ全体の作業状態(.mrk)の保存・復元用です。

## ツール

- 鉛筆: ハードエッジ、筆圧でサイズ可変
- ブラシ: ソフトエッジ、筆圧でサイズ可変
- 透明ブラシ: ソフトエッジ、筆圧でサイズと不透明度の両方が変化
- 消しゴム: ハードエッジで消去
- ドットペン: 1px固定、アンチエイリアスなし
- バケツ塗り: 4方向連結領域を塗りつぶし

メイン/サブ/透明色のスウォッチをクリックすると現在の色が切り替わります。透明色を選んだ状態で描くと、そのツールの形のまま消しゴムのように消せます。

## バリエーション表示

「表示」メニューから、現在のキャンバスだけを拡大する「単体フィッティング」、全バリエーションを一度に並べる「全体フィッティング」、全バリエーションのサイズを現在のものに揃える「サイズを揃える」が使えます。

## 既知の制約

- `.clip`書き出しは非公式のリバースエンジニアリング実装(libclip)を使っています。CLIP STUDIO PAINT側の仕様変更で将来動かなくなる可能性があります。
- ベクター・テキスト・トーン・3Dレイヤーは読み書きとも非対応です。
